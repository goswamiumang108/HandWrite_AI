custom_digits/

  val/0/*.png ... val/9/*.png
  test/0/*.png ... test/9/*.png

Split by writer when possible: photographs or examples from the same writer should
not appear in both the training and test set. Use real PNG/JPEG images. No examples
are distributed with this project. Classes must be named 0, 1, ..., 9.
